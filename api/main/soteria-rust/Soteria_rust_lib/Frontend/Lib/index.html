A target Cargo built, and the files it emitted for it.

val artifacts_of_output : string list -> artifact list

The artifacts Cargo built, as listed by the compiler-artifact messages of its JSON output.

Cargo will print different JSON messages, one per line. We are interested in the compiler-artifact messages, that have the following shape:

{
  "reason": "compiler-artifact",
  "target": { "name": "plugin", ... },
  "filenames": [
    "/path/to/plugin/target/<target>/debug/libplugin.rlib",
    "/path/to/plugin/target/<target>/debug/build/plugin/<hash>/out/libplugin-<hash>.rmeta"
  ],
  ...
}

See also: compiler-artifact documentation

val rustc_flags : t -> artifact list -> string list

The rustc flags needed to compile against lib, given the built artifacts for it.

val flags_file : t -> string

File used to cache the rustc flags of a library. Allows --no-compile-plugins to reuse the last build.

val compile : t -> string list

Builds lib and returns the rustc flags to compile against it. If --no-compile-plugins is set, the build is skipped and the flags recorded by the last one are reused.
