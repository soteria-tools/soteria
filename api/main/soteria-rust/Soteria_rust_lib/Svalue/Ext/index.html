and ('sc, 'ag) block_value =
  1. | Scalar of 'sc
  2. | Aggregate of 'ag * Charon.Types.ty

The value inside a block: either a scalar or an aggregate that can be split further.

and ('sc, 'ag, 'ofs, 'sz) block = {
  1. value : ('sc, 'ag) block_value;
  2. offset : 'ofs;
  3. size : 'sz;
}

A block of an encoded value: a value, along with the offset it is at and the size it spans. ty is Some iff the value is a whole aggregate of that type.
