Module Encoding.Ptr_sort

Raw pointers are encoded as a pair datatype of location and offset, declared on the fly through Solvers.Decls. Exposed to allow extensions to depend on it.

A pointer of width n is encoded as a datatype with two fields, both bitvectors of width n: the location and the offset.

val name : int -> string

The SMT-LIB sort for n-bit pointers.

val con : int -> string

The SMT-LIB constructor for n-bit pointers; receives the location and offset as arguments.

val mk_ptr : int -> Smt.sexp -> Smt.sexp -> Smt.sexp

The SMT-LIB constructor for n-bit pointers, applied to the location and offset terms.

val loc_sel : int -> string

The SMT-LIB selector for the location of n-bit pointers.

val get_loc : int -> Smt.sexp -> Smt.sexp

The SMT-LIB selector for the location of n-bit pointers, applied to a pointer term.

val ofs_sel : int -> string

The SMT-LIB selector for the offset of n-bit pointers.

val get_ofs : int -> Smt.sexp -> Smt.sexp

The SMT-LIB selector for the offset of n-bit pointers, applied to a pointer term.
