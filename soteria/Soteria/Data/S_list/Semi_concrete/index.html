Module S_list.Semi_concrete

Operations on semi-concrete lists: lists whose structure (length and order) is concrete, but whose elements are symbolic.

val sort : leq:('a -> 'a -> Symex.Value.sbool Symex.Value.t) -> 'a list -> 'a list Symex.t

sort ~leq l sorts the list l according to the symbolic comparison leq, using an insertion sort; if comparisons are symbolic, this may branch.
